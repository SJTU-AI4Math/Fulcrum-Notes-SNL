| 1.2.1 | BasicAnalysis.def.field | definition | Field | Uses `BasicAnalysis.ctxt.field`. `F` with `(add, mul, zero, one)` is a field iff: `add` is associative and commutative with identity `zero` and for every `x : F` an additive inverse `neg x` with `add x (neg x) = zero`; `mul` is associative and commutative with identity `one`, and every `x : F` with `x ≠ zero` admits `inv x` with `mul x (inv x) = one`; `mul` distributes over `add`, i.e. `mul x (add y z) = add (mul x y) (mul x z)`; and `one ≠ zero`. |
| 1.2.2 | BasicAnalysis.def.linear_order | definition | Linear Order | Uses `BasicAnalysis.ctxt.field`. `lt : F → F → Prop` is a linear (total) order iff it is irreflexive (`¬ lt x x`), transitive (`lt x y → lt y z → lt x z`), and satisfies trichotomy: for all `x y : F` exactly one of `lt x y`, `x = y`, `lt y x` holds. Write `x < y := lt x y` and `x ≤ y := (x < y) ∨ (x = y)`. |
| 1.2.3 | BasicAnalysis.def.ordered_field | definition | Ordered Field | Uses `BasicAnalysis.ctxt.field`. `(F, add, mul, zero, one, lt)` is an ordered field iff it is a field (`BasicAnalysis.def.field`), `lt` is a linear order (`BasicAnalysis.def.linear_order`), and the two compatibility axioms hold: (i) translation invariance, `x < y → add x z < add y z` for all `z : F`; (ii) positivity of products, `zero < x → zero < y → zero < mul x y`. |
| 1.2.3.1 | BasicAnalysis.property.ordered_field_basic | property | Elementary Consequences of the Order Axioms | Uses `BasicAnalysis.ctxt.field` with `F` an ordered field. For all `x y z : F`: `x < y ↔ zero < add y (neg x)`; `x < y → neg y < neg x`; `zero < z → (x < y ↔ mul x z < mul y z)`; `z < zero → (x < y ↔ mul y z < mul x z)`; `x ≠ zero → zero < mul x x`; in particular `zero < one`; and `zero < x → zero < inv x`. |
| 1.2.4 | BasicAnalysis.def.bounded_above | definition | Upper Bound, Bounded Above | Uses `BasicAnalysis.ctxt.field`. For `A : Set F` (i.e. `A : F → Prop`) and `b : F`, `b` is an upper bound of `A` iff `∀ x : F, A x → x ≤ b`. `A` is bounded above iff `∃ b : F, b` is an upper bound of `A`. Dually, `b` is a lower bound iff `∀ x : F, A x → b ≤ x`, and `A` is bounded below iff such `b` exists; `A` is bounded iff it is bounded above and below. |
| 1.2.5 | BasicAnalysis.def.supremum | definition | Supremum (Least Upper Bound) | Uses `BasicAnalysis.ctxt.field`. For `A : Set F` and `s : F`, `s = sup A` iff (i) `s` is an upper bound of `A`, and (ii) `s` is least among upper bounds: `∀ b : F, (∀ x : F, A x → x ≤ b) → s ≤ b`. Equivalently (ii'): `∀ ε : F, zero < ε → ∃ x : F, A x ∧ add s (neg ε) < x`. |
| 1.2.6 | BasicAnalysis.def.infimum | definition | Infimum (Greatest Lower Bound) | Uses `BasicAnalysis.ctxt.field`. For `A : Set F` and `i : F`, `i = inf A` iff `i` is a lower bound of `A` and `∀ b : F, (∀ x : F, A x → b ≤ x) → b ≤ i`. Equivalently, the second clause reads: `∀ ε : F, zero < ε → ∃ x : F, A x ∧ x < add i ε`. |
| 1.2.5.1 | BasicAnalysis.theorem.sup_unique | theorem | Uniqueness of the Supremum | Uses `BasicAnalysis.ctxt.field`. For `A : Set F`, if `s₁` and `s₂` both satisfy `BasicAnalysis.def.supremum` for `A`, then `s₁ = s₂`. The same holds for infima. |
| 1.2.5.1.1 | BasicAnalysis.proof.sup_unique | proof | Proof of Uniqueness of the Supremum | Since `s₁` is an upper bound and `s₂` is least among upper bounds, `s₂ ≤ s₁`. Symmetrically `s₁ ≤ s₂`. Antisymmetry of `≤` (from trichotomy in `BasicAnalysis.def.linear_order`) gives `s₁ = s₂`. |
| 1.2.7 | BasicAnalysis.axiom.completeness | axiom | Completeness Axiom (Least Upper Bound Property) | Uses `BasicAnalysis.ctxt.field`. `F` is order-complete iff every `A : Set F` that is nonempty (`∃ x : F, A x`) and bounded above admits a supremum in `F`: `∃ s : F, s = sup A` in the sense of `BasicAnalysis.def.supremum`. This axiom fails in ℚ and is what distinguishes ℝ. |
| 1.2.8 | BasicAnalysis.def.reals | definition | The Real Numbers ℝ | ℝ is defined as a complete ordered field: a type `ℝ` with `(add, mul, 0, 1, <)` satisfying `BasicAnalysis.def.ordered_field` together with `BasicAnalysis.axiom.completeness`. All subsequent entries in `BasicAnalysis` work over this fixed structure. |
| 1.2.8.1 | BasicAnalysis.theorem.reals_unique | theorem | Uniqueness of ℝ up to Order-Field Isomorphism | Any two complete ordered fields `F₁` and `F₂` are isomorphic: there exists a bijection `φ : F₁ → F₂` with `φ (add x y) = add (φ x) (φ y)`, `φ (mul x y) = mul (φ x) (φ y)`, and `x < y ↔ φ x < φ y`. Moreover such `φ` is unique. |
| 1.2.8.2 | BasicAnalysis.remark.reals_construction | remark | Remark: Constructions of ℝ | Intuition and provenance. The axioms above are realised by concrete constructions from ℚ: Dedekind cuts (a real is a downward-closed nonempty proper subset of ℚ without a greatest element, so completeness is nearly definitional) and Cauchy-sequence completion (ℝ is the quotient of Cauchy sequences of rationals by the null-difference equivalence, so completeness appears as Cauchy completeness). By `BasicAnalysis.theorem.reals_unique` the choice is immaterial for analysis. |
| 1.2.7.1 | BasicAnalysis.theorem.inf_from_sup | theorem | Greatest Lower Bound Property | In ℝ, every nonempty `A : Set ℝ` bounded below admits an infimum. |
| 1.2.7.1.1 | BasicAnalysis.proof.inf_from_sup | proof | Proof of the Greatest Lower Bound Property | Let `B := { b : ℝ | ∀ x : ℝ, A x → b ≤ x }` be the set of lower bounds of `A`. `B` is nonempty by hypothesis and bounded above by any element of `A`. By `BasicAnalysis.axiom.completeness` put `s := sup B`. Every `x` with `A x` is an upper bound of `B`, hence `s ≤ x`, so `s ∈ B`; being the largest element of `B`, `s = inf A`. |
| 1.3 | BasicAnalysis.subsec.arch | subsection | Archimedean Property and Density | Consequences of completeness governing how ℕ, ℤ and ℚ sit inside ℝ. |
| 1.3.1 | BasicAnalysis.theorem.archimedes | theorem | Archimedean Property | For every `x : ℝ` there exists `n : ℕ` with `x < n` (identifying `n : ℕ` with its image in ℝ under the canonical embedding). Equivalently: for all `x y : ℝ` with `0 < x`, there exists `n : ℕ` with `y < n · x`; equivalently `∀ ε : ℝ, 0 < ε → ∃ n : ℕ, 1 / (n + 1) < ε`. |
| 1.3.1.1 | BasicAnalysis.proof.archimedes | proof | Proof of the Archimedean Property | Suppose ℕ (as a subset of ℝ) were bounded above. It is nonempty, so by `BasicAnalysis.axiom.completeness` `s := sup ℕ` exists. Then `s − 1` is not an upper bound, so there is `n : ℕ` with `s − 1 < n`, whence `s < n + 1 ∈ ℕ`, contradicting that `s` is an upper bound. Hence ℕ is unbounded above, which is the statement. |
| 1.3.1.2 | BasicAnalysis.remark.non_archimedean | remark | Remark: Ordered Fields Failing Archimedes | The Archimedean property is not an order-field theorem: the field of rational functions ℝ(t) ordered by eventual sign at `+∞` is an ordered field in which `t` exceeds every integer. Thus `BasicAnalysis.theorem.archimedes` genuinely consumes completeness, and infinitesimals (`0 < ε < 1/n` for all `n`) are impossible in ℝ. |
| 1.3.2 | BasicAnalysis.theorem.floor | theorem | Existence of the Integer Part | For every `x : ℝ` there is a unique `m : ℤ` with `m ≤ x < m + 1`. This `m` is written `⌊x⌋`. |
| 1.3.3 | BasicAnalysis.theorem.q_dense | theorem | Density of ℚ in ℝ | For all `x y : ℝ` with `x < y` there exists `q : ℚ` with `x < q < y`. |
| 1.3.3.1 | BasicAnalysis.proof.q_dense | proof | Proof of the Density of ℚ | By `BasicAnalysis.theorem.archimedes` choose `n : ℕ` with `1 / n < y − x`, i.e. `n · (y − x) > 1`. Put `m := ⌊n x⌋ + 1` using `BasicAnalysis.theorem.floor`, so `m − 1 ≤ n x < m`. Then `n x < m ≤ n x + 1 < n y`, and dividing by `n > 0` gives `x < m / n < y`; take `q := m / n`. |
| 1.3.4 | BasicAnalysis.theorem.irr_dense | theorem | Density of the Irrationals | For all `x y : ℝ` with `x < y` there exists `z : ℝ` with `x < z < y` and `z ∉ ℚ`. Proof sketch: apply `BasicAnalysis.theorem.q_dense` to `x − √2 < y − √2` to get `q : ℚ`, then take `z := q + √2`. |
| 1.3.5 | BasicAnalysis.theorem.sqrt2_exists | theorem | Existence of √2 | There exists a unique `x : ℝ` with `0 < x` and `x · x = 2`; moreover `x ∉ ℚ`. More generally, for every `y : ℝ` with `0 ≤ y` and every `n : ℕ` with `n ≥ 1` there is a unique `x : ℝ` with `0 ≤ x` and `xⁿ = y`. |
| 1.3.5.1 | BasicAnalysis.proof.sqrt2_exists | proof | Proof of the Existence of √2 | Let `A := { t : ℝ | 0 ≤ t ∧ t · t < 2 }`. `A` is nonempty (`1 ∈ A`) and bounded above by `2`, so `x := sup A` exists by `BasicAnalysis.axiom.completeness`. If `x · x < 2`, choosing `h := min(1, (2 − x²)/(2x + 1)) > 0` gives `(x + h)² < 2`, contradicting that `x` is an upper bound. If `x · x > 2`, choosing `h := (x² − 2)/(2x) > 0` gives `(x − h)² > 2`, so `x − h` is a smaller upper bound, contradicting minimality. Hence `x · x = 2`. Irrationality follows from the standard parity argument on a reduced fraction `p/q`. |

| 2.2 | BasicAnalysis.subsec.limit | subsection | The Limit of a Sequence | The ε–N definition, uniqueness, boundedness, and the eventually/frequently vocabulary. |
| 2.2.1 | BasicAnalysis.def.sequence | definition | Real Sequence | A real sequence is a function `a : ℕ → ℝ`; the value at `n` is written `a_n` and the whole object `(a_n)_{n∈ℕ}`. A sequence is not its image set: `(a_n) = ((−1)^n)` has two-element image `{−1, 1}` but is a distinct object from any enumeration of that set. |
| 2.2.2 | BasicAnalysis.def.eventually | definition | Eventually and Frequently | Uses `BasicAnalysis.ctxt.seq`. For a predicate `P : ℕ → Prop`: `P` holds *eventually* iff `∃ N : ℕ, ∀ n : ℕ, n ≥ N → P n`; `P` holds *frequently* (infinitely often) iff `∀ N : ℕ, ∃ n : ℕ, n ≥ N ∧ P n`. These are dual: `¬(eventually P) ↔ frequently (¬P)`. |
| 2.2.3 | BasicAnalysis.def.limit | definition | Limit of a Sequence (ε–N) | Uses `BasicAnalysis.ctxt.seq`. `a` converges to `L`, written `lim_{n→∞} a_n = L` or `a_n → L`, iff `∀ ε : ℝ, 0 < ε → ∃ N : ℕ, ∀ n : ℕ, n ≥ N → \ | a_n − L\ | < ε`. Equivalently, using `BasicAnalysis.def.neighbourhood` and `BasicAnalysis.def.eventually`: for every `ε > 0`, `a_n ∈ U(L, ε)` eventually. `a` is convergent iff `∃ L : ℝ, a_n → L`; otherwise divergent. |
| 2.2.3.1 | BasicAnalysis.remark.limit_quantifier | remark | Remark: Reading the ε–N Quantifier Block | Intuition. The alternation `∀ε ∃N ∀n≥N` is an adversarial game: the opponent picks the tolerance `ε` first, and only then may one choose the threshold `N`, so `N` may depend on `ε` but never the reverse. Swapping to `∃N ∀ε` gives the far stronger statement `a_n = L` eventually. Replacing `< ε` by `≤ ε`, or `0 < ε` by `0 < ε < 1`, or `n ≥ N` by `n > N`, all yield equivalent definitions. |
| 2.2.3.2 | BasicAnalysis.example.limit_one_over_n | example | Example: `1/n → 0` | Uses `BasicAnalysis.ctxt.seq` with `a_n := 1/(n+1)`. Given `ε > 0`, `BasicAnalysis.theorem.archimedes` supplies `N : ℕ` with `1/(N+1) < ε`; for `n ≥ N` we get `\ | a_n − 0\ | = 1/(n+1) ≤ 1/(N+1) < ε`. Hence `lim 1/(n+1) = 0`. |
| 2.2.3.3 | BasicAnalysis.example.limit_geometric | example | Example: Geometric Sequence Tends to Zero | Let `q : ℝ` with `\ | q\ | < 1`. Write `\ | q\ | = 1/(1+h)` with `h > 0`. Bernoulli's inequality gives `(1+h)ⁿ ≥ 1 + n h`, so `\ | qⁿ − 0\ | ≤ 1/(1 + n h)`. Given `ε > 0` pick `N > (1/ε − 1)/h` by `BasicAnalysis.theorem.archimedes`; then `n ≥ N` implies `\ | qⁿ\ | < ε`. |
| 2.2.3.4 | BasicAnalysis.counterexample.limit_alternating | counterexample | Counterexample: `(−1)ⁿ` Has No Limit | Suppose `(−1)ⁿ → L`. Take `ε := 1`. | 2.2.4 | BasicAnalysis.def.bounded_seq | definition | Bounded Sequence | Uses `BasicAnalysis.ctxt.seq`. `a` is bounded iff `∃ M : ℝ, ∀ n : ℕ, \ | a_n\ | ≤ M`; bounded above iff `∃ M : ℝ, ∀ n, a_n ≤ M`; bounded below iff `∃ m : ℝ, ∀ n, m ≤ a_n`. | 2.3 | BasicAnalysis.subsec.algebra | subsection | Algebra of Limits | Compatibility of the limit operator with the field operations, order, and the squeeze principle. |
| 2.3.1 | BasicAnalysis.theorem.limit_add | theorem | Limit of a Sum and Scalar Multiple | Uses `BasicAnalysis.ctxt.seq`. If `a_n → L` and `b_n → M` then `a_n + b_n → L + M` and `c · a_n → c · L` for every `c : ℝ`; in particular `a_n − b_n → L − M`. For `n ≥ max(N₁,N₂)`, `BasicAnalysis.theorem.triangle` yields `\ | (a_n + b_n) − (L + M)\ | ≤ \ | a_n − L\ | + \ | b_n − M\ | < ε`. |
| 2.3.2 | BasicAnalysis.theorem.limit_mul | theorem | Limit of a Product | Uses `BasicAnalysis.ctxt.seq`. If `a_n → L` and `b_n → M` then `a_n · b_n → L · M`. |
| 2.3.2.1 | BasicAnalysis.proof.limit_mul | proof | Proof of the Product Rule | Write `a_n b_n − L M = a_n (b_n − M) + M (a_n − L)`. By `BasicAnalysis.theorem.conv_implies_bounded` fix `K > 0` with `\ | a_n\ | ≤ K` for all `n`, and enlarge `K` so that `\ | M\ | ≤ K`. Given `ε > 0`, choose `N` beyond which `\ | b_n − M\ | < ε/(2K)` and `\ | a_n − L\ | < ε/(2K)`; then `\ | a_n b_n − L M\ | ≤ K\ | b_n − M\ | + K\ | a_n − L\ | < ε`. |
| 2.3.3 | BasicAnalysis.theorem.limit_div | theorem | Limit of a Quotient | Uses `BasicAnalysis.ctxt.seq`. If `a_n → L`, `b_n → M`, `M ≠ 0`, and `b_n ≠ 0` for all `n`, then `a_n / b_n → L / M`. Key step: by `BasicAnalysis.theorem.limit_local_sign` applied to `\ | b_n\ | `, there is `N` with `\ | b_n\ | > \ | M\ | /2` for `n ≥ N`, so `\ | 1/b_n − 1/M\ | = \ | M − b_n\ | / (\ | b_n\ | \ | M\ | ) ≤ 2\ | M − b_n\ | / \ | M\ | ²`. |
| 2.3.4 | BasicAnalysis.theorem.squeeze | theorem | Squeeze Theorem | Uses `BasicAnalysis.ctxt.seq`. Let `a b c : ℕ → ℝ` with `a_n ≤ b_n ≤ c_n` eventually. If `a_n → L` and `c_n → L` then `b_n → L`. |
| 2.3.4.1 | BasicAnalysis.proof.squeeze | proof | Proof of the Squeeze Theorem | Given `ε > 0` choose `N` beyond which the sandwich holds together with `L − ε < a_n` and `c_n < L + ε`. Then `L − ε < a_n ≤ b_n ≤ c_n < L + ε`, i.e. `\ | b_n − L\ | < ε`. |
| 2.3.4.2 | BasicAnalysis.corollary.abs_limit | corollary | Limit of the Absolute Value | If `a_n → L` then `\ | a_n\ | → \ | L\ | `, since `\ | \ | a_n\ | − \ | L\ | \ | ≤ \ | a_n − L\ | ` by the reverse triangle inequality of `BasicAnalysis.theorem.triangle`. The converse holds only for `L = 0`: `a_n → 0 ↔ \ | a_n\ | → 0`; for `a_n := (−1)ⁿ`, `\ | a_n\ | → 1` while `a_n` diverges. |
| 2.3.2.2 | BasicAnalysis.corollary.limit_root | corollary | Limits and Powers/Roots | If `a_n → L` then `a_n^k → L^k` for every fixed `k : ℕ` (induction on `k` via `BasicAnalysis.theorem.limit_mul`); and if additionally `a_n ≥ 0` then `a_n^{1/k} → L^{1/k}`. |
| 2.4 | BasicAnalysis.subsec.completeness | subsection | The Completeness Theorems for Sequences | Monotone convergence, nested intervals, Bolzano–Weierstrass and the Cauchy criterion — four mutually equivalent formulations of the completeness of ℝ at the level of sequences. |
| 2.4.1 | BasicAnalysis.def.monotone | definition | Monotone Sequence | Uses `BasicAnalysis.ctxt.seq`. `a` is increasing iff `∀ n : ℕ, a_n ≤ a_{n+1}`; strictly increasing iff `a_n < a_{n+1}`; decreasing and strictly decreasing dually. `a` is monotone iff it is increasing or decreasing. |
| 2.4.1.1 | BasicAnalysis.theorem.monotone_convergence | theorem | Monotone Convergence Theorem | Uses `BasicAnalysis.ctxt.seq`. If `a` is increasing and bounded above, then `a` converges and `lim a_n = sup { x : ℝ \ | ∃ n, x = a_n }`. Dually, a decreasing sequence bounded below converges to the infimum of its image. Consequently every monotone sequence in ℝ either converges or is unbounded (diverging to `±∞`). |
| 2.4.1.1.1 | BasicAnalysis.proof.monotone_convergence | proof | Proof of the Monotone Convergence Theorem | Let `A := { x : ℝ \ | ∃ n, x = a_n }`, nonempty and bounded above; by `BasicAnalysis.axiom.completeness` set `L := sup A`. Given `ε > 0`, `L − ε` is not an upper bound, so there is `N` with `a_N > L − ε`. Monotonicity gives `L − ε < a_N ≤ a_n ≤ L` for all `n ≥ N`, hence `\ | a_n − L\ | < ε`. |
| 2.4.1.1.2 | BasicAnalysis.example.euler_e | example | Example: The Sequence `(1 + 1/n)ⁿ` | Uses `BasicAnalysis.ctxt.seq` with `a_n := (1 + 1/n)ⁿ` for `n ≥ 1`. By the AM–GM inequality `a_n` is strictly increasing, and `b_n := (1 + 1/n)^{n+1}` is strictly decreasing with `a_n < b_n ≤ b_1 = 4`. Hence `a` is increasing and bounded above, so by `BasicAnalysis.theorem.monotone_convergence` it converges; its limit is defined to be `e`, and `2 < e < 4` (in fact `e ≈ 2.71828`, irrational). |
| 2.4.2 | BasicAnalysis.theorem.nested_intervals | theorem | Nested Interval Theorem | Let `I_n := [a_n, b_n]` be closed bounded intervals with `I_{n+1} ⊆ I_n` for all `n`. Then `⋂_{n∈ℕ} I_n ≠ ∅`. If moreover `b_n − a_n → 0`, the intersection is a single point `ξ`, and `a_n → ξ`, `b_n → ξ`. Closedness and boundedness are both necessary: `(0, 1/n)` and `[n, +∞)` have empty intersection. |
| 2.4.2.1 | BasicAnalysis.proof.nested_intervals | proof | Proof of the Nested Interval Theorem | Nesting makes `a` increasing and `b` decreasing, with `a_n ≤ b_m` for all `n, m`. So `a` is bounded above by `b_0`; put `ξ := sup { a_n }`, which exists by `BasicAnalysis.axiom.completeness`. Each `b_m` is an upper bound of `{a_n}`, hence `a_n ≤ ξ ≤ b_n` for all `n`, i.e. `ξ ∈ ⋂ I_n`. If `b_n − a_n → 0` and `ξ, ξ' ∈ ⋂ I_n` then `\ | ξ − ξ'\ | ≤ b_n − a_n → 0`, so `ξ = ξ'`; the squeeze theorem `BasicAnalysis.theorem.squeeze` gives `a_n → ξ` and `b_n → ξ`. |
| 2.4.3 | BasicAnalysis.def.subsequence | definition | Subsequence | Uses `BasicAnalysis.ctxt.seq` and `BasicAnalysis.ctxt.seq.index`. Given `a : ℕ → ℝ` and a strictly increasing `k : ℕ → ℕ`, the subsequence is the composite `a ∘ k : ℕ → ℝ`, written `(a_{n_k})_{k∈ℕ}` with `n_k := k(k)`. Strict monotonicity forces `k(j) ≥ j` for all `j`, which is the workhorse inequality in subsequence proofs. |
| 2.4.3.1 | BasicAnalysis.theorem.subseq_limit | theorem | Subsequences Inherit the Limit | Uses `BasicAnalysis.ctxt.seq`, `BasicAnalysis.ctxt.seq.index`. If `a_n → L` then `a_{n_k} → L` for every strictly increasing `k`. Contrapositive test for divergence: if two subsequences of `a` converge to different limits, `a` diverges. Conversely, if every subsequence of `a` has a further subsequence converging to `L`, then `a_n → L`. |
| 2.4.3.1.1 | BasicAnalysis.proof.subseq_limit | proof | Proof that Subsequences Inherit the Limit | Given `ε > 0` take `N` with `\ | a_n − L\ | < ε` for `n ≥ N`. Since `k(j) ≥ j`, for `j ≥ N` we have `n_j = k(j) ≥ N`, hence `\ | a_{n_j} − L\ | < ε`. |
| 2.4.4 | BasicAnalysis.lemma.monotone_subseq | lemma | Every Sequence Has a Monotone Subsequence | Uses `BasicAnalysis.ctxt.seq`. Every `a : ℕ → ℝ` admits a monotone subsequence. Proof idea: call `m : ℕ` a *peak* iff `∀ n > m, a_n ≤ a_m`. If there are infinitely many peaks, enumerating them gives a decreasing subsequence; if there are finitely many, past the last peak one can always choose a strictly larger term, yielding an increasing subsequence. |
| 2.4.5 | BasicAnalysis.theorem.bolzano_weierstrass | theorem | Bolzano–Weierstrass Theorem | Uses `BasicAnalysis.ctxt.seq`. Every bounded sequence `a : ℕ → ℝ` admits a convergent subsequence. Set form: every infinite bounded `A : Set ℝ` has an accumulation point in ℝ. |
| 2.4.5.1 | BasicAnalysis.proof.bolzano_weierstrass | proof | Proof of Bolzano–Weierstrass | By `BasicAnalysis.lemma.monotone_subseq` extract a monotone subsequence; it is bounded because `a` is, so `BasicAnalysis.theorem.monotone_convergence` makes it convergent. Alternative bisection proof: start with `[A, B] ⊇ image(a)`, repeatedly halve, keeping at each step a half containing `a_n` for infinitely many `n`; `BasicAnalysis.theorem.nested_intervals` with lengths `(B−A)/2ⁿ → 0` gives a point `ξ`, and choosing indices `n_0 < n_1 < …` with `a_{n_k} ∈ I_k` yields `a_{n_k} → ξ`. |
| 2.4.6 | BasicAnalysis.def.cluster_point | definition | Cluster Point of a Sequence | Uses `BasicAnalysis.ctxt.seq`. `L : ℝ` is a cluster (subsequential limit) point of `a` iff `∀ ε : ℝ, 0 < ε → ∀ N : ℕ, ∃ n ≥ N, \ | a_n − L\ | < ε`; i.e. `a_n ∈ U(L, ε)` frequently in the sense of `BasicAnalysis.def.eventually`. Equivalently, `L` is a cluster point iff some subsequence of `a` converges to `L`. A sequence converges to `L` iff it is bounded and `L` is its only cluster point. |
| 2.4.7 | BasicAnalysis.def.cauchy | definition | Cauchy Sequence | Uses `BasicAnalysis.ctxt.seq`. `a` is Cauchy iff `∀ ε : ℝ, 0 < ε → ∃ N : ℕ, ∀ m n : ℕ, m ≥ N → n ≥ N → \ | a_m − a_n\ | < ε`. Equivalent form: `∀ ε > 0, ∃ N, ∀ n ≥ N, ∀ p : ℕ, \ | a_{n+p} − a_n\ | < ε`. Note that the pointwise-in-`p` weakening `∀ p fixed, \ | a_{n+p} − a_n\ | → 0` is strictly weaker and does not imply Cauchy. |
| 2.4.7.1 | BasicAnalysis.counterexample.cauchy_pointwise | counterexample | Counterexample: Vanishing Consecutive Gaps Do Not Imply Cauchy | Take `a_n := Σ_{j=1}^{n} 1/j` (harmonic partial sums). Then `a_{n+1} − a_n = 1/(n+1) → 0`, yet `a_{2n} − a_n ≥ 1/2` for every `n`, so `a` fails the Cauchy condition of `BasicAnalysis.def.cauchy` at `ε = 1/2` and diverges. |
| 2.4.7.2 | BasicAnalysis.theorem.cauchy_criterion | theorem | Cauchy Convergence Criterion | Uses `BasicAnalysis.ctxt.seq`. `a : ℕ → ℝ` converges iff `a` is Cauchy. (ℝ is a complete metric space with the distance of `BasicAnalysis.def.distance`.) The corresponding statement in ℚ is false, e.g. the decimal truncations of `√2`. |
| 2.4.7.2.1 | BasicAnalysis.proof.cauchy_criterion | proof | Proof of the Cauchy Criterion | (⇒) If `a_n → L`, given `ε > 0` take `N` with `\ | a_n − L\ | < ε/2` for `n ≥ N`; then `\ | a_m − a_n\ | ≤ \ | a_m − L\ | + \ | L − a_n\ | < ε` for `m, n ≥ N`. (⇐) A Cauchy sequence is bounded (apply the definition at `ε = 1` and take a maximum over the finitely many earlier terms), so by `BasicAnalysis.theorem.bolzano_weierstrass` some subsequence satisfies `a_{n_k} → L`. Given `ε > 0` pick `N` from the Cauchy condition at `ε/2` and `k` with `n_k ≥ N` and `\ | a_{n_k} − L\ | < ε/2`; then `n ≥ N` gives `\ | a_n − L\ | ≤ \ | a_n − a_{n_k}\ | + \ | a_{n_k} − L\ | < ε`. |
| 2.4.8 | BasicAnalysis.remark.completeness_equivalences | remark | Remark: Seven Equivalent Forms of Completeness | Intuition and architecture. Over an Archimedean ordered field the following are mutually equivalent: the least-upper-bound axiom (`BasicAnalysis.axiom.completeness`), the monotone convergence theorem, the nested interval theorem, Bolzano–Weierstrass, the Cauchy criterion, the Heine–Borel finite-subcover property, and the existence of accumulation points for infinite bounded sets. Choosing any one as an axiom derives the rest; the standard cycle is LUB ⇒ monotone ⇒ nested ⇒ BW ⇒ Cauchy ⇒ LUB. |
| 2.5 | BasicAnalysis.subsec.limsup | subsection | Upper and Lower Limits | `limsup` and `liminf` as the always-defined extended-real substitutes for `lim`. |
| 2.5.1 | BasicAnalysis.def.extended_reals | definition | Extended Real Line | `ℝ̄ := ℝ ⊎ {−∞, +∞}` with the order extended by `−∞ < x < +∞` for every `x : ℝ`, and the partial arithmetic `x + (+∞) = +∞` for `x ≠ −∞`, `x · (+∞) = +∞` for `x > 0`, `x / (±∞) = 0`; the expressions `(+∞) + (−∞)`, `0 · (±∞)`, `(±∞)/(±∞)` remain undefined. In ℝ̄ every subset has a supremum and an infimum, with `sup ∅ = −∞`, `inf ∅ = +∞`. |
| 2.5.2 | BasicAnalysis.def.limsup | definition | Upper Limit (limsup) | Uses `BasicAnalysis.ctxt.seq`. Put `s_N := sup { a_n : ℝ \ | n ≥ N } : ℝ̄`. The sequence `(s_N)` is decreasing, so define `limsup_{n→∞} a_n := inf_{N∈ℕ} s_N = lim_{N→∞} sup_{n ≥ N} a_n : ℝ̄`. Characterisation for `L : ℝ`: `limsup a_n = L` iff for every `ε > 0`, `a_n < L + ε` eventually and `a_n > L − ε` frequently (`BasicAnalysis.def.eventually`). |
| 2.5.3 | BasicAnalysis.def.liminf | definition | Lower Limit (liminf) | Uses `BasicAnalysis.ctxt.seq`. Put `i_N := inf { a_n \ | n ≥ N }`; `(i_N)` is increasing and `liminf_{n→∞} a_n := sup_{N∈ℕ} i_N : ℝ̄`. Duality: `liminf a_n = − limsup (−a_n)`. Characterisation for `L : ℝ`: for every `ε > 0`, `a_n > L − ε` eventually and `a_n < L + ε` frequently. |
| 2.5.2.1 | BasicAnalysis.property.limsup_exists | property | limsup and liminf Always Exist in ℝ̄ | For every `a : ℕ → ℝ`, `limsup a_n` and `liminf a_n` exist as elements of `ℝ̄` and satisfy `liminf a_n ≤ limsup a_n`. They are finite simultaneously with `a` being bounded: `limsup a_n < +∞` iff `a` is bounded above; `liminf a_n > −∞` iff `a` is bounded below. |
| 2.5.2.2 | BasicAnalysis.theorem.limsup_cluster | theorem | limsup/liminf as Extreme Cluster Points | Uses `BasicAnalysis.ctxt.seq`. Let `C ⊆ ℝ̄` be the set of cluster points of `a` in the sense of `BasicAnalysis.def.cluster_point` (allowing `±∞`). Then `C ≠ ∅`, `limsup a_n = max C` and `liminf a_n = min C`; in particular both are themselves cluster points, i.e. attained by some subsequence. |
| 2.5.2.3 | BasicAnalysis.theorem.limsup_criterion | theorem | Convergence Criterion via limsup and liminf | Uses `BasicAnalysis.ctxt.seq`. `a` converges to `L : ℝ` iff `limsup a_n = liminf a_n = L` (both finite). Likewise `a_n → +∞` iff `liminf a_n = +∞`, and `a_n → −∞` iff `limsup a_n = −∞`. |
| 2.5.2.3.1 | BasicAnalysis.proof.limsup_criterion | proof | Proof of the limsup/liminf Criterion | (⇒) If `a_n → L`, then for `ε > 0` eventually `L − ε < a_n < L + ε`, so for large `N`, `L − ε ≤ i_N ≤ s_N ≤ L + ε`; letting `ε → 0` gives `liminf = limsup = L`. (⇐) If `liminf = limsup = L`, then for `ε > 0` there is `N` with `L − ε < i_N ≤ a_n ≤ s_N < L + ε` for all `n ≥ N`, i.e. `\ | a_n − L\ | < ε`. |
| 2.5.2.4 | BasicAnalysis.property.limsup_subadditive | property | Subadditivity of limsup | For bounded `a, b : ℕ → ℝ`: `limsup (a_n + b_n) ≤ limsup a_n + limsup b_n` and `liminf a_n + liminf b_n ≤ liminf (a_n + b_n)`, with equality when one of the two sequences converges. Both inequalities can be strict: `a_n := (−1)ⁿ`, `b_n := (−1)^{n+1}` give `limsup(a_n+b_n) = 0 < 2`. For nonnegative sequences, `limsup (a_n b_n) ≤ (limsup a_n)(limsup b_n)`. |
| 2.5.2.5 | BasicAnalysis.remark.limsup_intuition | remark | Remark: Reading limsup as an Eventual Ceiling | Intuition. `limsup a_n` is the smallest ceiling the sequence eventually stays under, up to any slack `ε`: it is exceeded only finitely often but approached infinitely often. Discarding the first `N` terms can only lower the ceiling, and the monotone limit of these ceilings is `limsup`. This is why `limsup` exists unconditionally while `lim` does not — one has replaced the two-sided pinning by a one-sided one. |
| 2.6 | BasicAnalysis.subsec.infinite | subsection | Infinitesimals and Infinities | Null sequences, divergence to `±∞`, and their calculus. |
| 2.6.1 | BasicAnalysis.def.infinitesimal | definition | Infinitesimal (Null Sequence) | Uses `BasicAnalysis.ctxt.seq`. `a` is an infinitesimal iff `a_n → 0`, i.e. `∀ ε > 0, ∃ N, ∀ n ≥ N, \ | a_n\ | < ε`. Standard reformulation of convergence: `a_n → L` iff `α_n := a_n − L` is an infinitesimal, so every convergent sequence factors as `a_n = L + α_n`. |
| 2.6.1.1 | BasicAnalysis.property.infinitesimal_algebra | property | Algebra of Infinitesimals | If `α` and `β` are infinitesimals then so are `α + β`, `α − β`, `c · α` for `c : ℝ`, and `α · β`. If `α` is an infinitesimal and `b` is bounded then `α_n · b_n` is an infinitesimal — note that `b` need not converge, e.g. `(1/n) · sin n → 0`. Quotients of infinitesimals are indeterminate. |
| 2.6.2 | BasicAnalysis.def.diverge_infinity | definition | Divergence to Infinity | Uses `BasicAnalysis.ctxt.seq`. `a_n → +∞` iff `∀ M : ℝ, ∃ N : ℕ, ∀ n ≥ N, a_n > M`; `a_n → −∞` iff `∀ M : ℝ, ∃ N, ∀ n ≥ N, a_n < −M`; `a_n → ∞` (infinitely large in absolute value) iff `∀ M : ℝ, ∃ N, ∀ n ≥ N, \ | a_n\ | > M`. A sequence with `a_n → ±∞` is called an infinity; it is unbounded, hence divergent in the sense of `BasicAnalysis.def.limit`. |
| 2.6.2.1 | BasicAnalysis.property.infinity_reciprocal | property | Reciprocity between Infinitesimals and Infinities | Uses `BasicAnalysis.ctxt.seq`. If `a_n ≠ 0` for all `n`, then `a_n → ∞` iff `1/a_n → 0`. Refinement with sign: if `a_n → 0` and `a_n > 0` eventually, then `1/a_n → +∞`. Also `a_n → +∞` and `b_n` bounded below imply `a_n + b_n → +∞`; `a_n → +∞` and `b_n ≥ c > 0` imply `a_n b_n → +∞`. |
| 2.6.2.2 | BasicAnalysis.counterexample.unbounded_not_infinite | counterexample | Counterexample: Unbounded ≠ Infinitely Large | Let `a_n := n` for even `n` and `a_n := 0` for odd `n`. Then `a` is unbounded (`BasicAnalysis.def.bounded_seq` fails) but `a_n → ∞` fails: at `M = 1` no `N` works, because arbitrarily large odd indices give `\ | a_n\ | = 0`. Hence "unbounded" is strictly weaker than "infinitely large". |
| 2.6.3 | BasicAnalysis.remark.indeterminate_forms | remark | Remark: Indeterminate Forms | Intuition. The symbolic patterns `∞ − ∞`, `0 · ∞`, `0/0`, `∞/∞`, `1^∞`, `0⁰`, `∞⁰` are indeterminate: knowing only the limits of the constituents does not determine the limit of the combination. With `a_n := n`, choosing `b_n := n`, `n + c`, or `n²` makes `a_n − b_n` tend to `0`, `−c`, or `−∞`; `(1 + 1/n)ⁿ → e` versus `1ⁿ → 1` shows `1^∞` is genuinely undetermined. Resolving such forms requires rate comparison (Stolz, ratio tests, or later L'Hôpital). |
| 2.7 | BasicAnalysis.subsec.standard_limits | subsection | Standard Limits and Techniques | The reference limits and the two comparison tools (Stolz, ratio) used to evaluate them. |
| 2.7.1 | BasicAnalysis.theorem.limit_nth_root_n | theorem | `n^{1/n} → 1` | `lim_{n→∞} n^{1/n} = 1`. Proof: write `n^{1/n} = 1 + h_n` with `h_n ≥ 0`; the binomial theorem gives `n = (1+h_n)ⁿ ≥ C(n,2) h_n² = n(n−1)h_n²/2`, so `0 ≤ h_n ≤ √(2/(n−1)) → 0`, and `BasicAnalysis.theorem.squeeze` applies. |
| 2.7.2 | BasicAnalysis.theorem.limit_nth_root_a | theorem | `a^{1/n} → 1` for `a > 0` | For every `a : ℝ` with `a > 0`, `lim_{n→∞} a^{1/n} = 1`. Proof: for `a ≥ 1` Bernoulli gives `1 ≤ a^{1/n} ≤ 1 + (a−1)/n`; for `0 < a < 1` apply the previous case to `1/a` and use `BasicAnalysis.theorem.limit_div`. |
| 2.7.3 | BasicAnalysis.theorem.limit_poly_over_exp | theorem | Polynomial versus Exponential versus Factorial Growth | For every fixed `α : ℝ` and `q : ℝ` with `q > 1`: `lim n^α / qⁿ = 0`; for every fixed `c : ℝ`: `lim cⁿ / n! = 0`; and `lim n! / nⁿ = 0`. Ordering of growth rates: `ln n ≺ n^α ≺ qⁿ ≺ n! ≺ nⁿ`, where `x ≺ y` means `x_n / y_n → 0`. |
| 2.7.4 | BasicAnalysis.theorem.limit_e | theorem | The Limit Defining `e` | `lim_{n→∞} (1 + 1/n)ⁿ = e` (see `BasicAnalysis.example.euler_e`), and more generally `lim (1 + x/n)ⁿ = e^x` for every `x : ℝ`, and `lim (1 + 1/a_n)^{a_n} = e` for any real sequence with `a_n → ∞`. Equivalently `e = Σ_{k=0}^{∞} 1/k!`, with error bound `\ | e − Σ_{k=0}^{n} 1/k!\ | < 1/(n · n!)`. |
| 2.7.5 | BasicAnalysis.theorem.stolz | theorem | Stolz–Cesàro Theorem | Uses `BasicAnalysis.ctxt.seq`. Let `b : ℕ → ℝ` be strictly increasing with `b_n → +∞` (the `∞/∞` case). If `lim (a_{n+1} − a_n)/(b_{n+1} − b_n) = L : ℝ̄` then `lim a_n / b_n = L`. The `0/0` case: if `a_n → 0`, `b_n → 0`, `b` strictly decreasing, and the same difference quotient tends to `L`, then `a_n/b_n → L`. The converse fails, so Stolz is a sufficient criterion only. |
| 2.7.5.1 | BasicAnalysis.corollary.cesaro_mean | corollary | Cesàro Mean | Uses `BasicAnalysis.ctxt.seq`. If `a_n → L : ℝ̄` then the arithmetic means satisfy `(a_1 + … + a_n)/n → L`. If moreover `a_n > 0`, the geometric means satisfy `(a_1 ⋯ a_n)^{1/n} → L`, and if `a_{n+1}/a_n → L` then `a_n^{1/n} → L`. The converses fail: `a_n := (−1)ⁿ` has Cesàro mean tending to `0` while `a` diverges. |

| 2.8 | BasicAnalysis.subsec.divergent | subsection | Divergent Sequences | Classification of non-convergence and the standard tests for it. |
| 2.8.1 | BasicAnalysis.def.divergent | definition | Divergent Sequence | Uses `BasicAnalysis.ctxt.seq`. `a` is divergent iff `¬ ∃ L : ℝ, a_n → L`, i.e. `∀ L : ℝ, ∃ ε > 0, ∀ N : ℕ, ∃ n ≥ N, \ | a_n − L\ | ≥ ε`. Divergence splits into: proper divergence to `±∞` (`BasicAnalysis.def.diverge_infinity`); oscillatory divergence with at least two distinct cluster points, in which case `liminf a_n < limsup a_n`; and unbounded oscillation. |
| 2.8.1.1 | BasicAnalysis.theorem.divergence_tests | theorem | Criteria for Divergence | Uses `BasicAnalysis.ctxt.seq`. Each of the following implies that `a` diverges: (i) `a` is unbounded (contrapositive of `BasicAnalysis.theorem.conv_implies_bounded`); (ii) two subsequences converge to distinct limits (`BasicAnalysis.theorem.subseq_limit`); (iii) `liminf a_n ≠ limsup a_n` (`BasicAnalysis.theorem.limsup_criterion`); (iv) the Cauchy condition fails, i.e. `∃ ε₀ > 0, ∀ N, ∃ m,n ≥ N, \ | a_m − a_n\ | ≥ ε₀` (`BasicAnalysis.theorem.cauchy_criterion`). |
| 2.8.1.1.1 | BasicAnalysis.example.divergent_sin | example | Example: `(sin n)` Diverges | The sequence `a_n := sin n` is bounded by `1` but divergent: by the equidistribution of `{n/(2π)}` mod 1 (Weyl), the set of cluster points of `(sin n)` is the whole interval `[−1, 1]`, so `liminf = −1 < 1 = limsup` and criterion (iii) of `BasicAnalysis.theorem.divergence_tests` applies. An elementary argument uses the identity `sin(n+1) + sin(n−1) = 2 sin n cos 1` to derive a contradiction from `sin n → L`. |

Cf. `BasicAnalysis.counterexample.cauchy_pointwise`. |
| 2.8.1.2 | BasicAnalysis.remark.divergence_vs_infinity | remark | Remark: Divergence Is Not Just "Going to Infinity" | Intuition. In everyday usage "divergent" suggests blow-up, but the formal negation of `BasicAnalysis.def.limit` is merely "no real number is approached". Bounded oscillation (`(−1)ⁿ`), unbounded oscillation (`n·(−1)ⁿ`), and proper divergence (`n`) are all divergent, yet only the last two are unbounded and only the last one is an infinity. Writing `lim a_n = +∞` is a notational convenience for `BasicAnalysis.def.diverge_infinity`, not an assertion that a limit exists in ℝ. |
