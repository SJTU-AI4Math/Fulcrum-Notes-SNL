# Type Theory — imported Lean course files

The nine `.lean` files in this directory are copied byte-for-byte from
[`SJTU-AI4Math/Summer-School-2026`](https://github.com/SJTU-AI4Math/Summer-School-2026/tree/939b2ad669ce11038b5edde25be94f4b47624824/LectureNotes),
commit `939b2ad669ce11038b5edde25be94f4b47624824`, directory `LectureNotes/`.

Original filenames, comments, examples, proofs, and exercise placeholders are
preserved for subsequent author organization. These are separate course files,
not one combined import module. No SNL conversion or reorganization is applied.

All nine files were checked individually with Lean 4.28.0 and the existing
project Mathlib dependencies. A successful check does not mean that exercise
placeholders (`sorry`) have been filled in.
